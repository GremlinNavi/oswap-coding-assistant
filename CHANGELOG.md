# Changelog

## 0.1.0 - 2026-09-02

Initial reference implementation release candidate.

- local-first PowerShell coding assistance through Ollama
- model selection through `OSWAP_LLM_MODEL`
- no automatic execution of generated code
- local multilingual dictionary lookup
- provenance/licence requirements for dictionary records
- machine-readable OSWAP command contracts
- country/domain site-profile manifest for `oswap.ca`, `oswap.us`, and `oswap.jp`
- locale resource bundles for Canada, the United States, and Japan
- release, localization, domain, security, and contribution documentation

Future backend adapters, dictionary importers, and GUI implementation remain separate development-cycle work.
